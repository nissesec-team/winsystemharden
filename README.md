# WinSystemHarden (Free Edition)

**Offline System Hardening for Windows 10/11.**

WinSystemHarden applies 32 hardening rules based on CIS Benchmarks and NSA guidelines to secure your Windows system. It disables high-risk services (like SMBv1) and closes unnecessary ports. If anything breaks, one click puts everything back.

## ✨ Key Features
- **32 Hardening Rules:** Covers Network, Service, and System hardening.
- **CIS & NSA Based:** Follows strict industry security benchmarks.
- **One-Click Rollback:** Revert system changes to any previous restore point.
- **100% Offline:** No cloud, no telemetry, no data collection.
- **Free Edition:** Completely free to use.
